# Nokia 6070 SMS screen emulator

Pixel-accurate 128×160 Nokia 6070 screen for screencasts: SMS received, inbox, a tennis game,
two screen themes, phone body, photo overlay (LCD grid, noise, dirt, aberration, defocus, reflection),
3D camera, and the timed shot 120 with Capture to .mp4.

Open `index.html` (works straight from disk, no server). Settings are kept in the browser;
on the first visit the author's settings from `default-settings.js` are used.
